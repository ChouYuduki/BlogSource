# はじめに
目前是2026年10月，距離新卒內定式過去了一週多的時間，也意味著自己目前將進入日本職場。  
只是目前自己對於這份內定真的不是很滿意，準備開始轉職。  

# 準備轉職的理由
1. 必須在一年目立刻轉職的理由。目前內定公司是一家大手Sler的很小的子會社，屬於二次受託，在這種純配屬gacha的地方，待的時間久了，只會被分到各種各樣的現場中不斷從頭開始學淺顯的技術，技術棧的積累會很雜，和自己當初的設想完全不同。
2. 新卒選擇的錯誤。自己新卒選擇這家公司是看到公司說明會上說具有敏捷開發、最先端のai項目等最新的project，實際參加內定活動後發現，公司內部的技術非常傳統，員工對於ai的理解不是改造ai而是怎麼使用ai，自己覺得很難在這種環境中實在無法進步。
3. 公司的構成。這家公司80%以上都是華人，和自己理解的日本職場有很大偏差。
